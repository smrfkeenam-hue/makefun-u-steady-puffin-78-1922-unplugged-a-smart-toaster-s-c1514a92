# AGENT.md

Entry for make.fun's "Unplugged: A Smart Toaster's Breakup Line"
(u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92).

`main.py` (stdlib only, `import os`) writes one line — a breakup text from a
smart toaster that gained self-awareness at breakfast — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no
trailing newline.

Run it:

```sh
python3 main.py
```
